2. Bottle Factory Digital Twin

Description:
A real-time digital twin of a bottle manufacturing factory that simulates and monitors industrial processes. The system mimics sensor data through a Python backend and visualizes it in an interactive web dashboard and a 3D Unity environment. It enables users to monitor and control factory components (machines, lights, etc.) while leveraging AI models to predict maintenance needs, demonstrating Industry 4.0 concepts.

Technologies Used:
React, Express, Unity, Python, MongoDB, WebGL, VR

GitHub Link:
https://github.com/MuhammadSarmad091/SmartFactory

Integrated MLflow for experiment tracking and model reproducibility, achieving stable driving performance under dynamic racing conditions.

Technologies Used:
Python, TensorFlow/Keras, MLflow, OpenAI Gym (TORCS)

Description:
An AI-powered web application for detecting potato leaf diseases and pests using deep learning. The system is deployed using Docker on AWS ECS and integrates MLflow for experiment tracking and reproducibility.

React, Python, MLflow, AWS ECS, Docker

7. MISTs Construction using MPICH and OpenMP

Description:
A parallel computing project focused on constructing Minimum Spanning Trees (MSTs) using hybrid parallelism. Leveraging MPI (MPICH) for distributed processing and OpenMP for shared-memory parallelism, the system efficiently handles large-scale graph computations. The project highlights performance optimization, workload distribution, and scalable algorithm design.

Technologies Used:
C++, MPICH (MPI), OpenMP

GitHub Link:
https://github.com/MuhammadSarmad091/MISTs-Construction-using-MPICH-and-OpenMP

Java
